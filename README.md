# Personal Portfolio Website

This is a personal portfolio website available at [www.michalbeno.eu](http://www.michalbeno.eu).

## Content

The portfolio is intended to be divided into two main sections:
-   **Software Projects:** This section is currently active and showcases my software development work.
-   **Landscape Projects:** This section is planned for the future (TBD).

## Deployment

The website is automatically deployed to WebSupport hosting via SSH using a GitHub Actions workflow. The deployment is triggered on every push to the `production` branch.
